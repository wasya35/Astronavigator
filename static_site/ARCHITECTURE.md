# Астронавигатор — слепок архитектуры (статическая версия)

> Версия от 2026-09-14. Это снимок текущего устройства сайта в виде
> **чисто клиентского статического комплекта** (без бэкенда). Всё, что раньше
> считал Python/Flask, теперь считается прямо в браузере на движке
> astronomy-engine — том же, что уже работает в биржевом терминале.

## 1. Смысл переезда

Было: **Flask + pyswisseph + Docker + Timeweb App Platform** — сервер считал
эфемериды и отдавал JSON на страницы. Минусы: нужен работающий контейнер,
healthcheck, деплой, домен через облако — точка отказа и стоимость.

Стало: **набор статических файлов** (`.html` + `.js` + `.css`), которые
загружаются на любой обычный хостинг (Спринтхост) как есть. Расчёт эфемерид,
накшатр, даш, лагны и часовых поясов — целиком в браузере пользователя.
Сервер не нужен вообще: ни Python, ни Docker, ни healthcheck.

Это возможно потому, что «тяжёлые» части (сидерическая эфемерида, накшатры,
СБЧ) уже были собраны на JS для терминала. Здесь мы их переиспользуем и
дописываем джйотиш-слой: Навамша D9, Вимшоттари-даша, граха-дришти, лагна,
титхи и конверсию местного времени рождения в UTC.

## 2. Дерево файлов

```
site/
├── index.html         Стр.1 «Небо сейчас» (публичная, бесплатно)
├── settings.html      «Моя карта» — ввод рождения → лагна, планеты, махадаша
├── periods.html       «Периоды» — каскад Маха/Антар/Пратьянтар
├── order.html         «Разбор» — пакеты + заявка в Telegram
├── method.html        «О методе» — статический текст
├── privacy.html       Политика конфиденциальности (черновик)
├── offer.html         Публичная оферта (черновик)
│
├── css/
│   └── style.css      Единая тема (светлая, без мистики; РСЯ-safe)
│
├── vendor/
│   └── astronomy.browser.min.js   Движок эфемерид (Don Cross, MIT), из терминала
│
└── js/
    ├── astro.js       window.LunAstro: долготы тел, айянамша Лахири,
    │                  сидерические долготы, накшатра/пада (из терминала)
    ├── sbc.js         window.LunSBC: Сарватобхадра-чакра (из терминала;
    │                  пока не подключена к страницам — задел на след. шаг)
    ├── content.js     window.CONTENT: тексты накшатр (27), фоны махадаш/
    │                  антардаш, тексты аспектов, правила дришти
    │                  (сгенерировано из YAML старого сайта)
    ├── cities.js      window.CITIES: справочник ~130 городов РФ/СНГ
    │                  (широта, долгота, IANA-часовой пояс) + поиск
    ├── jyotish.js     window.Jyotish: ГЛАВНЫЙ джйотиш-слой (см. §4)
    ├── chart.js       drawRasiChart(): SVG-квадрат в стиле Дж.Хоры
    ├── sky.js         логика стр.1 (небо + шкала времени)
    ├── settings.js    логика «Моей карты» (форма → расчёт → показ)
    └── periods.js     логика «Периодов»
```

## 3. Порядок загрузки скриптов (важно)

На страницах с расчётом подключение строго в этом порядке:

```
astronomy.browser.min.js   → определяет window.Astronomy
astro.js                   → определяет window.LunAstro (нужен Astronomy)
content.js                 → window.CONTENT
cities.js                  → window.CITIES
jyotish.js                 → window.Jyotish (нужны LunAstro + CONTENT)
chart.js                   → window.drawRasiChart
<страничный>.js            → sky.js / settings.js / periods.js
```

`method/order/privacy/offer` — чистый статический текст, скрипты не нужны.

## 4. Ядро расчёта — `js/jyotish.js` (`window.Jyotish`)

Единственная публичная точка входа для страниц. Всё синхронно (без сети).

| Метод | Вход | Выход |
|---|---|---|
| `sky(tsMs)` | момент, мс | `{planets, moon(+накшатра), drishti}` |
| `natal(birth)` | `{date,time,place,…}` | `{lagna, planets(+дома,D9), cascade}` |
| `periods(birth)` | `{date,time,place}` | `{mahadashas, antardashas, pratyantardashas, current_*}` |
| `lagna(ms,lat,lon)` | момент, координаты | асцендент (сидерический) |
| `vimshottari(moonLon,ms)` | долгота Луны, рождение | три уровня даш |
| `localToUtc(y,mo,d,h,mi,tz)` | локальное время | UTC-мс |

Внутри реализовано:

- **Позиции планет** — `LunAstro.sidLonOf` (тропик минус айянамша Лахири),
  знак/градус/накшатра/пада, ретроградность (по знаку производной долготы),
  Раху/Кету по среднему узлу.
- **Навамша D9** — стартовый знак по стихии + номер навамши.
- **Граха-дришти** — аспекты по знакам: 7-й у всех; спец. Марс 4/8,
  Юпитер 5/9, Сатурн 3/10; взаимные и соединения; тексты из `CONTENT`.
- **Луна дня** — титхи, пакша (шукла/кришна), освещённость, накшатра с
  описанием (фон, что усиливается/искажается, благоприятно/с осторожностью).
- **Вимшоттари-даша** — три уровня (Маха→Антар→Пратьянтар), от накшатры
  Луны рождения, доли 120-летнего цикла, текущий период помечается.
- **Лагна** — по звёздному времени (`Astronomy.SiderealTime`), широте,
  наклону эклиптики; тропический асцендент → сидерический (минус айянамша).
- **Часовой пояс рождения** — `Intl.DateTimeFormat` с IANA-tz города.
  База часовых поясов браузера включает историческое декретное время СССР,
  поэтому старые даты рождения конвертируются корректно без бэкенда.

## 5. Проверка точности

Лагна сверена с эталонным Python-расчётом (Swiss Ephemeris):

```
15.04.1988, 09:30, Нерюнгри (Asia/Yakutsk)
  Python (эталон): Лагна Близнецы 7.94° сидерически
  Этот движок:     Лагна Близнецы 7.93° (накшатра Ардра)
  Расхождение:     0.01° — в пределах округления
```

Страницы прогнаны через headless-Chromium: небо, «Моя карта» и «Периоды»
отрисовываются без ошибок в консоли, карты-SVG строятся, каскад даш считается.

## 6. Данные пользователя и приватность

- Профиль рождения хранится **только** в `localStorage` браузера, чтобы не
  вводить заново. На сервер ничего не уходит — сервера нет.
- Никаких кук, трекеров и сторонних запросов в расчёте. Метрику/пиксель РСЯ
  (если понадобятся для рекламы) добавляем отдельным тегом при заливке.

## 7. Что намеренно оставлено на следующие шаги

- **СБЧ (Сарватобхадра-чакра)** — `sbc.js` уже в комплекте, но к страницам
  не подключён. Задел под «барометр качества дня» на стр.1.
- **Оплата/подписка** — кнопки «Оплатить» ведут на страницу заявки (Telegram).
  Реальный платёжный провайдер подключается отдельно.
- **Тексты накшатр × лагна / планета × накшатра** — расширенный слой
  интерпретаций «Моей карты» (владелец готовит текстовый файл).
- **Панчанга/титхи-описания, карта года (Варшапхала), транзиты** — стр.5.

## 8. Как это заливается

Распаковать архив в корень сайта на Спринтхосте (или в поддомен
`astronavigator.…`). Никакой сборки, установки и запуска не требуется —
`index.html` открывается напрямую. Обновление = замена файлов.
