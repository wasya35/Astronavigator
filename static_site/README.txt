АСТРОНАВИГАТОР — статический сайт (без бэкенда)
================================================

Что это
-------
Готовый комплект сайта, который работает сам по себе в браузере.
Никакого Python, Docker, сервера и настройки не нужно. Все расчёты
(положение планет, накшатры, даши, лагна) идут прямо в браузере
посетителя на движке astronomy-engine.

Как залить на Спринтхост (или любой обычный хостинг)
----------------------------------------------------
1. Распаковать этот архив.
2. Загрузить ВСЁ содержимое (файлы index.html, папки css/ js/ vendor/ …)
   в корень сайта или в папку поддомена astronavigator.
   Проще всего — через файловый менеджер хостинга или по FTP.
3. Открыть сайт в браузере. Стартовая страница — index.html.

Важно: сохранять структуру папок. index.html ссылается на js/, css/,
vendor/ относительными путями. Если положить файлы вперемешку — не заработает.

Страницы
--------
index.html    — «Небо сейчас» (публичная, бесплатно)
settings.html — «Моя карта» (ввод данных рождения → карта и период)
periods.html  — «Периоды» (каскад даш; нужен профиль из «Моей карты»)
order.html    — «Разбор» (пакеты + заявка в Telegram)
method.html   — «О методе»
privacy.html  — политика конфиденциальности (черновик)
offer.html    — публичная оферта (черновик)

Обновление
----------
Просто заменить файлы новыми. Кэш браузера можно сбросить Ctrl+F5.

Приватность
-----------
Данные рождения хранятся только в браузере посетителя (localStorage),
на сервер ничего не отправляется.

Подробности устройства — в файле ARCHITECTURE.md.
